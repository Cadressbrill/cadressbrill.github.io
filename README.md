# Portfolio — Cadress Brill

Site statique (HTML, CSS, JavaScript) publié avec GitHub Pages.

## Structure

- `index.html` : contenu de la page
- `style.css` : mise en forme
- `script.js` : coordonnées (objet `CONFIG`) et icônes
- `images/` : photo de profil et captures des projets
- `cv/` : CV au format PDF

## Mise à jour des liens

Les coordonnées se modifient dans l'objet `CONFIG` de `script.js`.
Un champ laissé vide masque automatiquement le lien correspondant (LinkedIn, Facebook, lien ShopWave).
